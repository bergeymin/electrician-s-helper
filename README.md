# Electrician's Helper

Создай мобильный планировщик задач для электромонтажника (для личного использования).

Функционал:
1. Добавление и управление задачами (название, статус, срок, приоритет).
2. Выбор необходимых инструментов для задачи (каталог типового инструмента электрика + добавление своего: перфоратор, коронка 68 мм, лазерный уровень, стриппер и т.д.).
3. Список материалов к задаче с указанием количества и единиц измерения (подрозетники, кабель ВВГ-Пнг, дюбель-хомуты, клеммы WAGO и др.).
4. Чеклист подзадач внутри карточки с прогрессом выполнения.
5. Фильтрация по статусам (К выполнению, В работе, Готово) и возможность привязать задачу к объекту или помещению.
6. Удобный интерфейс, адаптированный под смартфоны.
